My Basic Website
================

Files:
- index.html: Website structure
- style.css: Website styling
- script.js: Button interaction
- assets/: Put images and other static files here

How to run:
1. Extract this ZIP file.
2. Open the my-website folder.
3. Double-click index.html to open it in your browser.

Cloudflare Pages:
For a plain HTML/CSS/JS site, publish the folder containing index.html.
No build command is required. The output directory should be the folder containing index.html.
